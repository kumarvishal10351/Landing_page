# Landing_page

A minimal, clean, responsive landing page inspired by the Telegram channel preview for SURAJ BHAI.

## Features
- Circular avatar profile photo (`assets/profile.jpg`)
- Bold serif channel name heading
- Configurable subscriber count
- Channel description with formatted text
- Telegram blue `JOIN CHANNEL` button linking directly to the channel
- 1-second countdown screen before the channel card is revealed
- Dark theme with low-contrast Telegram doodle SVG pattern (`assets/pattern.svg`)
- Fully responsive across mobile (320px–430px), tablet, and desktop viewports
- Ready for static deployment on Hostinger shared hosting (`public_html`)

## Files
- `index.html` - Semantic HTML structure & configurable details
- `style.css` - Pure CSS design & mobile responsive styles
- `assets/profile.jpg` - Channel profile photo
- `assets/pattern.svg` - Lightweight Telegram dark doodle background

## Deployment
Upload all files directly to your hosting server's `public_html` directory.
